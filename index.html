    How it works

    1. Listen. Your song is decoded and run through an FFT. For the low, mid and high frequency bands it measures where new energy appears: kick-ish, snare-ish and hat-ish onsets.
    2. Find the beat. Autocorrelation guesses the tempo, then a comb-filter search locks the exact BPM and bar position.
    3. Write the part. A style template gives how likely each drum is on each 16th note. Wherever the song has a real hit, that probability is boosted. Fills land at phrase ends and crashes where the song gets louder. A seeded random generator makes the same seed give the same beat every time.
    4. Play it. Every drum is synthesised live with the Web Audio API; there are no samples.

    This is a clever rule-based engine, not a trained AI model. It's fast, private and tweakable. Detection works best on songs with a steady tempo.
